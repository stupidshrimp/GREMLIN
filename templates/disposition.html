    Dispositioning explained

    How dispositioning in Excel works

    Excel is the offline version of the list on this page. Download the work orders for the asset you selected, fill in the disposition columns, then upload the same workbook to save them all at once. Nothing reaches the database until you upload it.

    Download Excel → Fill in the disposition columns → Upload Excel
    1. Select the asset and what to show first. The workbook holds the work orders that Show is set to: all of them, only those not reviewed yet, or the migrated ones still to confirm. The search box and the page you are on do not narrow it.
    2. Click Download Excel. The first sheet is one row per work order. The second, Lookup Lists, holds every code with its name and feeds the dropdowns, so leave it in the file.
    3. Fill in the disposition columns, highlighted from the header down: disposition_category, record_class, sub_asset, component_code, failure_mechanism_code, failure_mode_code, action_code, evidence and failure_cause_code are dropdowns. renewed_items takes component codes separated by commas; linked_wo the task ID a duplicate continues; qty and disposition_note are typed. Leave failure_cause_code blank to take the mechanism's default cause. A code typed rather than picked can be in any capitals, or its name (Contamination for CONT, PM reset for PM_RESET).
    4. Leave the rest alone. The grey columns are the work order as Limble recorded it and are never written back. mapped_record_id and task_id are how each row finds its work order: don't edit them, and don't copy a row.
    5. Click Upload Excel and choose the file. Only rows whose disposition columns differ from what is saved are saved, through the same checks as Save here, and recorded against your account.
    Worth knowing

    The headings and columns are locked; the cells aren't. Sort, filter, resize, and add or delete rows as you like, but the headings can't be retyped and columns can't be added, deleted or moved, so the upload always finds them. Review > Unprotect Sheet lifts the lock if you must; the upload still reads headings in other capitals or under the names this page uses, a column moved, and a title typed above the table, and tells you about any column it didn't read.

    One refused row saves none. The upload lists every refused row at once, by the row number Excel shows, its task and why; fix them and upload the file again.

    Your team's newer work is kept. Each row remembers the disposition it was downloaded with. If somebody changes a work order here after your download and you leave its row alone, the upload keeps their newer one and says so. If you both changed it, the upload stops and names the row: delete it to keep theirs, or download a fresh workbook and redo it there.

    Uploading the same file twice is harmless: the second time every row already matches.
