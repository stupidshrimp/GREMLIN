    Dispositioning explained

    How dispositioning on Excel works

    Excel is the offline version of the table on this page. Download the entries for the asset you selected, fill in the disposition columns in Excel, then upload the same workbook to save them all at once. Nothing reaches the database until you upload it back.

    Download Excel → Fill in the disposition columns → Disposition via Excel
    1. Select the asset and record type first. The workbook is built from the Asset Number and Record Type chosen in Step 1, and it holds every eligible entry for that selection — the Rows selector, the search box, and the page you are on do not narrow it.
    2. Click Download Excel. You get <asset>_wo_dispositions.xlsx (or _pm_ for PM reset events). The first sheet is one row per record; the second sheet, Lookup Lists, feeds the dropdowns, so leave it in the file.
    3. Fill in the disposition columns. They are the last columns on the sheet, and most of them are dropdowns:

      Both record types

      • disposition_notes — free text. Required for HELD_AMBIGUOUS and EXCLUDED_MIXED_CONTAMINATING.
      • disposition_category — dropdown.
      • record_class — dropdown.
      • include_in_weibull_candidate — TRUE or FALSE.

      Work orders

      • failure_mode and failure_mechanism — pick from the dropdown, or type a brand-new name and it is created for this asset on import. Only INCLUDED_FAILURE rows become Weibull-usable.

      PM reset events

      • pm_reset_decision, reset_target_failure_mode, reset_target_failure_mechanism, pm_reset_renewal_rationale. A PM becomes Weibull-usable only as INCLUDED_PM_RESET_EVENT with APPROVED_RESET, a reset target, and a rationale.
    4. Leave the rest of the sheet alone. mapped_record_id is how each row finds its record: never edit it, delete a row, or add one. The task, date, downtime, note and failure-narrative columns are read-only — edits there are ignored on import, so the workbook can never overwrite what the maintenance team recorded in Limble.
    5. Click Disposition via Excel and choose the file. Rows are matched back by mapped_record_id, rows you did not change are skipped, and the rest are saved as the current disposition — the same result as editing them on this page and clicking Save Dispositions. The page then reloads with the imported values in place.
    Worth knowing

    Changing a failure mode or mechanism? Clear the matching failure_mode_id / failure_mechanism_id cell (or reset_target_…_id for PMs) in the same row. Those id columns win when they are filled in, so a new name typed beside an old id is read as no change at all.

    PMs cannot invent taxonomy. A reset target has to be an existing work-order failure mode/mechanism, so choose those from the dropdown. Work orders are the only place a new mode or mechanism can be named.

    One wrong row stops the whole import. A mapped_record_id that does not belong to the selected asset and record type is refused and nothing is saved — usually a sign the workbook was downloaded for a different asset or record type.

    Downloading is open to everyone; importing writes, so it needs an editor account. Re-uploading the same file twice is safe: the second pass finds nothing changed.
