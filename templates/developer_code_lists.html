One row per code, retired codes included, list by list in the order the dropdowns show them.

  • The yellow columns are the ones an upload reads. The grey work_orders_using column is there to read: how many work orders' current dispositions use the code.

Upload

Each row is one code, found by its code_list and code. A new pair adds a code; an existing one is changed to read as the row does, and a row that already reads that way is left alone.

  • A code's spelling is its key. Retyping one adds a new code rather than renaming the old one; change its name instead.
  • Codes left out of the workbook are kept: an upload never deletes. Set is_active to FALSE to take a code off the dropdowns, or delete one nothing uses from the Code lists dialog on the Disposition page.
  • An empty sort_order puts a new code at the end of its list. An empty is_active or renews_item keeps what the code had (a new code is active and renews nothing).
  • default_cause_code is read for failure mechanisms only, and renews_item for actions only.
  • Every row is checked before anything is saved. One refused row refuses the upload and nothing changes; every refused row is listed, so they can all be fixed at once.
